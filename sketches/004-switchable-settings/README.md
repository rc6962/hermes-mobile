## Variant: Switchable workspace + settings

### Purpose
Demonstrate the combined direction requested by Rick: Soft Haven and Gentle Command as switchable themes, a settings drawer, an optional in-chat console, and scalable sessions.

### Demonstrated interactions
- Open the gear button to view standard and advanced settings.
- Switch between Soft Haven and Gentle Command without leaving the screen.
- Toggle the activity console in the chat.
- Use the session filter and View all conversations affordance.

### Important product boundary
The console shown here is intentionally a safe Hermes Console concept, not an arbitrary Android shell. Production implementation must redact secrets, validate configuration changes, and keep dangerous actions explicitly confirmed.
