# Hermes Mobile visual mockups

These are disposable design explorations. They do not modify production UI code.

Open each `index.html` in a browser or use the Hermes preview pane.

| Variant | Stance | Strongest quality | Trade-off |
|---|---|---|---|
| [Soft Haven](001-soft-haven/index.html) | Airy, calm, friendly | Lowest intimidation | Less technical density |
| [Sunlit Companion](002-sunlit-companion/index.html) | Warm, consumer-oriented | Most approachable | Less premium/operations feel |
| [Gentle Command](003-gentle-command/index.html) | Dark, focused, softened | Best continuity with current app | Still feels more technical |
| [Switchable workspace](004-switchable-settings/index.html) | Theme/settings/session concept | Demonstrates the requested product controls | Still a design prototype |

**Provisional recommendation:** use Soft Haven and Gentle Command as switchable themes, with the Switchable workspace interaction model. Start with Soft Haven or Gentle Command, then combine the winning layout with the preferred visual language.
